# Códigos e Estudos em Java ☕

Repositório dedicado ao armazenamento de códigos práticos, exercícios de fixação e anotações de estudo desenvolvidos em Java.

---

## 📂 Estrutura do Repositório

O conteúdo está organizado pelos tópicos e módulos abordados:

* **`TiposCuringa/`**: Exemplos práticos do uso de *Wildcards* (tipos curinga) em Generics (`? extends`, `? super`).
* **`TiposMap/`**: Exercícios e implementações utilizando a interface `Map` e coleções chave-valor (ex.: `HashMap`, `TreeMap`).
* **`SecaoDezoito/` e `SecaoDezoiExerPropost/`**: Conteúdos e exercícios práticos abordando interfaces, contratos e serviços.
* **`Exercicios/`, `ExercicoProposto/`, `Proposto/`, `ExercicioPropostoDezoito/`**: Exercícios propostos e desafios de lógica de programação orientada a objetos (POO).

---
